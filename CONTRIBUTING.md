# Contributing Guide

## Branch Naming

- Feature: `feature/<short-description>`
- Bugfix: `bugfix/<short-description>`
- Chore: `chore/<short-description>`

Examples:
- `feature/kid-task-list`
- `bugfix/fix-login-crash`

## Commit Message

Include a short description and (if exists) Jira ID:

- `KIDS-123: Add basic kid task list`
- `KIDS-201: Fix crash when creating task`

## Pull Request

Every PR should include:

- Background / Context
- What has been changed
- How to test (steps)
- Screenshots (if UI changes)
