# Kids Management

A web/mobile app for parents to create and manage daily tasks for kids, with simple gamification elements.

## Tech Stack

- Frontend: React / React Native (TBD)
- Backend: Node.js (Express or Nest, TBD)
- Language: TypeScript
- Package manager: npm / yarn / pnpm (choose one)

## Getting Started

```bash
# Install dependencies
npm install

# Run dev
